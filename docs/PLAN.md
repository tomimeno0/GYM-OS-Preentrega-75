# Plan de la reescritura

El pedido principal es bajar la complejidad al nivel del profesor, no aumentar el porcentaje sobre la arquitectura anterior. Esta copia parte de carpetas nuevas; no mezcla archivos de las entregas existentes.

1. Leer el repaso y los ejemplos de acceso y router del curso. Comparar su estructura con las capas anteriores.
2. Reescribir modelos explícitos y relaciones, conexión MySQL y acceso con CommonJS. Mantener contraseñas y claves fuera de las respuestas.
3. Reescribir cuenta, medidas, objetivos, progreso, rutinas y entrenamientos en funciones de controlador, con consultas visibles.
4. Completar el corte de nutrición manual y las llamadas directas a Cohere, sin servicios ni recuperación automática de fallos.
5. Reescribir las pantallas con estado local y Axios. Conservar confirmaciones y formularios al fallar.
6. Probar con MySQL real, cuentas sintéticas distintas, errores de validación, historia y API real. Luego recorrer la interfaz real y revisar tamaños de pantalla.
7. Documentar funciones y reparto de estudio en nueve guías dentro del mismo repositorio. Publicar código y documentación sin secretos ni datos de prueba.

El corte nominal se explica en ALCANCE.md. No equivale a certificación de cumplimiento literal del documento completo ni a medir el trabajo de personas.
